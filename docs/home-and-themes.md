# 首页与栏目主题

- `home` 是人物动画首页。点击原有“进入星火”按钮，四个栏目入口在当前场景上浮现；取消、Escape 或再次点击首页可收起。
- 首页画面保留，进入栏目时停止渲染，返回后继续显示，不重新加载原画与 WebGL 素材。栏目深链接首次打开时不下载首页素材。
- 四个公开栏目：空域（苍穹航迹）、简报（信息星图）、城市更新（城市线稿）、资料库（书卷拱廊）。
- 分享页使用映像主题，私人知识库使用翠色档案主题。文件详情与文件解读延续资料库主题。
- 统一深色阅读面板、文字对比度、导航、筛选器及弹窗；所有正文、公开数据路径、隐藏分享手势、知识库鉴权保持原有规则。
- 所有新背景由 `scripts/generate-universe-scenes.mjs` 以固定种子生成，为原创 SVG 图形，不含外部追踪或真实业务坐标。
- 本地预览：先 `npm run build`，再 `npm run preview`。预览仅将 `/data/` 的公开读取请求转发到正式站点，不转发凭据或私人知识库接口。
- 改版前源码位于标签 `backup-20261017-before-home-redesign`；详见 `docs/checkpoints/2026-10-17-before-home-redesign.md`。
