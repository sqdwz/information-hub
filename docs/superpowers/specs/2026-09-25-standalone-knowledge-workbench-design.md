# 独立知识工作台设计

日期：2026-09-25
状态：已批准实施

## 目标

把当前嵌在信息中心单页路由中的知识库拆成独立页面，同时保留其隐蔽入口。独立页面把只读知识记录组织成“提醒事项、日历、备忘录”三种互相关联的视图，视觉上借鉴苹果应用的清晰分区，但继续使用本站现有的玻璃质感、颜色、字体和交互语言。

本次不增加网页写入能力，不修改 GitHub 知识库中的记录，也不把知识库入口暴露到首页卡片、主导航或页脚导航。

## 访问链路

唯一入口链路为：

```text
信息中心首页
  -> 现有头像隐藏手势
  -> 隐藏的“演示与分享”二级页面
  -> 点击“知识库”入口
  -> knowledge.html 独立页面
```

- 头像隐藏手势恢复为打开现有二级页面，不直接打开知识库。
- 二级页面保留现有“演示”和“分享”内容，并增加一个明确可点击的“知识库”入口。
- 点击知识库入口执行正常页面跳转，不使用 iframe，也不在二级页面中展开知识内容。
- 独立页提供“返回隐蔽入口”操作，返回信息中心的二级页面。
- 直接访问 `knowledge.html` 仍必须通过现有身份认证；入口隐藏不作为安全措施。

## 页面结构

独立页使用一个统一工作台，而不是三个互相割裂的应用。

### 顶部区域

- 显示“知识库”标题、只读/认证状态、索引更新时间。
- 提供搜索、刷新索引、安全退出和返回二级页面。
- 主人会话可以继续打开现有只读分享令牌管理；分享会话不显示令牌管理。

### 提醒事项

- 展示分类为“日程”的知识记录。
- 按“近期、以后、未安排”组织，只允许依据结构化的明确日期分类。
- 不提供勾选完成、新增、修改、删除或拖动改期。
- 没有明确日程日期的记录进入“未安排”，不得用笔记创建时间或更新时间冒充日程日期。

### 日历

- 默认显示当前月，支持切换前后月份和返回今天。
- 只在存在明确结构化日程日期的日期上显示标记和数量。
- 点击日期只筛选并展示当天已有记录，不改变任何数据。
- 当前没有可定位日程时显示真实空状态，不生成示例事项。

### 备忘录

- 展示非“日程”类知识记录，并允许按分类和标签筛选。
- 保留标题、摘要、更新时间、项目和标签等真实索引字段。
- 点击记录进入独立页内的正文阅读视图，保留目录、Markdown 表格、任务列表、代码块和安全链接处理。
- 全局搜索继续覆盖索引字段和现有 Worker 提供的正文搜索。

### 响应式布局

- 桌面端采用提醒事项、日历、备忘录三栏协作布局；正文阅读时让阅读区域成为主区域。
- 窄屏按“提醒事项 -> 日历 -> 备忘录”纵向排列，避免横向滚动。
- 可交互目标不小于 44 x 44 像素，图标按钮提供可访问名称。

## 数据与安全边界

- 继续复用现有 `/api/knowledge/session`、`login`、`logout`、`index`、`search`、`item` 和令牌相关接口。
- Cloudflare Worker 继续以只读方式访问 `personal-knowledge-base`；前端不得获得 GitHub 凭据。
- 认证 Cookie、访问令牌有效期、登录限流、允许记录范围和私有响应缓存策略保持现有语义。
- 日历日期只接受索引中的显式结构化字段；允许兼容 `event_at`、`start_at` 或 `due_at`，但不从自然语言摘要中猜测日期。
- 现有不含上述字段的“日程”记录仍可在提醒事项的“未安排”中查看。
- 分享链接改为指向独立页面，并在令牌交换后移除地址栏中的一次性令牌。

## 文件边界

预计改动集中在：

- `index.html`：移除内嵌知识工作台，只保留二级页入口和所需共享对话框。
- `app.js`：恢复隐藏二级页入口逻辑，并处理知识库跳转。
- `knowledge.html`：独立知识工作台骨架与认证对话框。
- `knowledge.js`：适配独立页，增加只读提醒、月历和备忘录映射。
- `knowledge.css`：知识工作台独立样式，复用站点变量且不污染其他页面。
- `scripts/build.mjs`：把独立页面及其资源复制到构建目录。
- `src/worker.js`、`wrangler.jsonc`：仅在独立页路由或现有接口需要时做最小调整，不扩大写权限。
- 自动化测试：覆盖入口、日期映射、日历筛选、认证态和分享令牌跳转。

现有工作树中的动态分享目录、TraceRail 和 Worker 知识接口改动属于同一未完成批次，实施时会逐项核对，不覆盖或丢弃无关改动。

## 错误和空状态

- 未认证：显示登录对话框，不渲染私人索引内容。
- 索引读取失败：保留页面框架并显示可重试提示。
- 没有日程：提醒事项和日历分别显示空状态，备忘录仍可使用。
- 正文读取失败：仅正文区域显示失败和返回操作。
- 分享令牌无效或过期：显示明确错误，不退化为主人权限。

## 测试与验收

实现采用测试先行，并至少验证：

1. 头像隐藏手势只进入隐藏二级页面。
2. 首页、主导航和页脚不出现公开知识库入口。
3. 二级页面点击知识库后正常跳转到 `knowledge.html`。
4. 未认证访问独立页时出现认证界面，私人内容不提前渲染。
5. 只有明确日程日期会进入具体日期；无日期日程进入“未安排”。
6. 点击日历日期只筛选，不产生写请求。
7. 备忘录搜索、筛选、正文阅读和返回流程正常。
8. 主人会话与只读分享会话的令牌管理权限正确区分。
9. 构建成功，JavaScript 语法检查和 `git diff --check` 通过。
10. 在 1440 像素桌面和 390 x 844 手机视口完成真实浏览器验证：无横向溢出、无页面错误、44 x 44 触控目标和可访问名称合格。
