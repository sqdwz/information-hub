# 雾蓝紫染色玻璃

英文：Blue-Violet Tinted Glassmorphism / Acrylic Glass。

统一材质位于 `assets/css/tinted-glass.css`，在基础、行业简报和循迹样式之后加载。保持现有夜景插画、页面布局与交互，不使用白色渐变覆盖页面底部。

- 环境层：雾蓝色 18%，只整理背景。
- 内容层：蓝紫渐变 34%–38%，配合 20px blur / 115% saturation。
- 阅读层：偏蓝的 48% 底色，用于表格、全文以及密集文字卡片；密集卡片将此层叠加在内容染色上，因此最终合成不透明度高于 48%。
- 局部边缘：20% 细亮边、18% 顶部内高光、低强度蓝色投影。
- 正文：深蓝灰；页面标题和导航继续使用亮色。次要信息避免中性灰。
- 循迹：静止时透明，hover / 键盘聚焦时出现 20% 染色和模糊；手机按钮和模态抽屉使用更深的蓝紫染色，保证叠在卡片上仍可读。

当前覆盖聚合站的导航、卡片、表格、归档、内容要点详情与公告弹窗；独立文件解读站保持自身版式。欢迎页的独立视觉与原有语义状态色保持不变。不增加纹理资源或前端依赖。

浏览器验收：桌面 1440px、手机 390px，各功能页日期导航、刷新定位、详情链接；截图保存于忽略目录 `output/playwright/`。
